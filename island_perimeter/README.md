# Island Perimeter

This project contains a function that calculates the perimeter of an island represented by a grid of integers.

## Function

`island_perimeter(grid)`

- `0` represents water.
- `1` represents land.
- Each cell has a side length of 1.
- Cells are connected horizontally or vertically.

## Files

- `0-island_perimeter.py`: contains the `island_perimeter` function.

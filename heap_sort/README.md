# Heap Sort

This directory contains an implementation of the Heap sort algorithm in C.

## Files
- 0-heap_sort.c: Heap sort implementation
- sort.h: Header file with function prototypes
- 0-O: Time complexity notations for Heap sort

## Usage
- The function `heap_sort` sorts an array of integers in ascending order using the sift-down heap sort algorithm.
- The array is printed after each swap as required.

## Time Complexity
- Best case: O(nlog(n))
- Average case: O(nlog(n))
- Worst case: O(nlog(n))
